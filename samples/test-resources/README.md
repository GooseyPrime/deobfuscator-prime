# Made-up samples

These files were generated for the universal deobfuscator. They are not real malware, not real protected applications, and not produced by a commercial obfuscator.

- `made-up-obfuscated.jar` is a class with NOP padding, a redundant goto, and unreachable instructions.
- `made-up-obfuscated.js` is a tiny hand-written string-table script.
- `made-up-dotnet.exe` is a synthetic PE header with a CLR data directory. It is not a valid assembly.
- `made-up-native.exe` is a synthetic PE header without a CLR directory.
- `made-up-android.apk` is a ZIP that only contains a fake AndroidManifest.xml.
- `made-up-unknown.bin` is five arbitrary bytes.
